
# SadakYatri - Pothole Detection

Vision-based agentic road damage detection, monitoring and maintenance
prioritization system for Nepal.

Detects potholes from vehicle-mounted cameras, estimates severity, tags
them with GPS, merges repeat sightings from different vehicles into a
single tracked defect, and ranks which road damage should be repaired first.

Built with YOLOv11, object tracking, a Django backend, and an agentic
prioritization layer.

## Status

V1 - detector training. In development.

## Stack

Python, Ultralytics YOLOv11, OpenCV, Django, SQLite
